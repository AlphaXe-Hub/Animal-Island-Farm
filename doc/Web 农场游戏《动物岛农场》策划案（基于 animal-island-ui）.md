# Web农场游戏《动物岛农场》策划案（基于animal-island-ui）
## 一、游戏核心定位
### 1. 游戏名称
《动物岛农场》（Animal Island Farm）
### 2. 风格定位
**治愈休闲+动森风**，基于你指定的 **animal-island-ui** 开发，采用SVG有机形状、3D按压按钮、温暖质朴的自然UI质感，搭配明亮马卡龙色系、手绘风农场场景与萌系动物NPC，打造轻松无压力的田园经营体验。
### 3. 核心玩法
经典农场经营闭环：**开垦→播种→浇水/施肥→成熟收获→出售盈利→扩建农场/解锁道具**，叠加轻度社交与养成元素，适配碎片化游玩（单次5-15分钟）。
### 4. 目标用户
18-35岁都市年轻群体（白领、学生），喜欢治愈系游戏、模拟经营玩法，追求解压、轻松的游戏体验，偏好可爱风UI与低门槛操作。

## 二、UI设计规范（基于animal-island-ui）
### 1. 整体视觉
- **色彩体系**：主色（暖绿色#7cb342、浅木色#d7ccc8）、辅助色（暖黄#ffd54f、浅蓝#81d4fa）、中性色（米色#f5f5dc、深棕#5d4037），匹配组件库温暖自然调性。
- **形状风格**：全部按钮、弹窗、卡片采用**有机圆角/不规则SVG裁切**，无生硬直角；按钮添加3D按压动效，交互反馈柔和。
- **字体**：默认使用组件库内置的 `Noto Sans SC`，标题加粗、正文常规，搭配农场主题艺术数字（强化沉浸感）。
### 2. 核心页面UI规划
#### （1）登录/注册页
- 布局：顶部动森风农场Logo+萌系动物插画，中间输入框（组件库Input，带前后缀、一键清空）、注册/登录按钮（5种类型按钮选“温暖实心款”），底部版权+游客体验入口。
- 特色：Typewriter组件实现“欢迎来到动物岛农场”逐字打字机动画；Modal组件弹出注册协议/隐私政策（SVG有机形状弹窗，ESC可关闭）。
#### （2）农场主场景页（核心页）
- 布局（分3区）：
  - 顶部：状态栏（金币、钻石、体力、等级），用组件库Icon+Time组件显示在线时间；
  - 中间：农场主区域（网格农田、房屋、仓库、商店入口，2.5D俯视角，动森风手绘场景）；
  - 底部：功能栏（种植、背包、商店、任务、社交，用组件库Tabs组件实现切换，图标为萌系农场元素）。

- 交互：农田地块点击触发播种/浇水/收获（按钮按压反馈）；悬浮显示作物状态（生长阶段、剩余时间）；自定义手指光标（Cursor组件）增强沉浸感。
#### （3）商店/仓库/钱包页
- 商店：卡片式布局（组件库Card），分种子区、肥料区、道具区、装饰区；每个商品卡片含图标、名称、价格、购买按钮（加载状态用Switch组件动效）；支持搜索（Input组件+Select下拉分类）。

- 仓库：折叠面板（Collapse组件）分类展示（作物、种子、肥料、道具），支持批量选择、出售、移动；Divider组件分隔不同分类。
- 钱包：卡片显示金币/钻石数量、收支记录（表格用组件库基础样式），充值入口（Modal弹窗展示充值档位，按钮带3D动效）。
#### （4）个人中心页
- 布局：头像+昵称+等级（卡片）、基础信息（注册时间、农场规模、成就）、设置入口（账号安全、音效开关、主题切换——用组件库40+CSS变量实现一键换肤，无需重构）。

## 三、核心系统设计
### 1. 用户系统（注册/登录/成长）
#### （1）注册登录
- 方式：手机号+验证码、邮箱注册、游客登录（数据临时保存，绑定账号后同步）；
- 组件：Input（手机号/邮箱/验证码）、Button（获取验证码/注册/登录）、Checkbox（同意协议）、Modal（协议弹窗）。
#### （2）等级成长
- 规则：收获作物、完成任务、出售农产品获得经验，经验满自动升级；
- 奖励：升级解锁新农田、新种子/肥料、农场装饰、功能权限（如批量浇水）；
- 展示：状态栏等级图标+经验进度条（组件库基础样式改造）。
#### （3）个人数据
- 保存：用户信息、农场数据（农田状态、作物生长、仓库物资）、资产数据（金币、钻石）、任务进度；
- 同步：后端实时同步，前端localStorage缓存，防止数据丢失。

### 2. 农场种植系统（核心玩法）
#### （1）农田管理
- 初始：4块基础农田（可开垦），等级提升逐步解锁扩展（最多20块）；
- 状态：荒地→已开垦→已播种→生长中→成熟→收获后（循环）；
- 操作：点击荒地开垦（消耗少量金币），点击已开垦农田播种，生长中可浇水/施肥，成熟后收获。
#### （2）作物系统（分3类，适配不同周期）
| 类型 | 代表作物 | 生长周期 | 收益 | 解锁等级 |
| :--- | :--- | :--- | :--- | :--- |
| 短期（快收） | 小麦、胡萝卜、生菜 | 5-15分钟 | 低（基础金币） | 1级（初始） |
| 中期（稳收） | 玉米、番茄、土豆 | 30-60分钟 | 中（金币+少量经验） | 3级 |
| 长期（高收） | 草莓、西瓜、果树 | 2-8小时 | 高（金币+大量经验+稀有道具） | 5级/8级 |
- 特色：作物分四季适配（春：小麦；夏：西瓜；秋：玉米；冬：耐寒生菜），非季节作物生长减速、产量降低；随机触发天气（晴天/雨天/干旱），雨天自动浇水、干旱生长停滞，增加随机性。
#### （3）种子/肥料系统
- 种子：商店购买（基础种子金币、稀有种子钻石），仓库保存；分普通、优质、稀有（稀有种子产出高，概率变异）。
- 肥料：分普通（加速1倍生长，金币购买）、高级（加速2倍+增产20%，钻石购买/任务奖励）、特效（防病虫害+加速，活动专属）；背包点击肥料，再点击作物使用。
#### （4）生长与收获
- 生长：实时计时（离线也正常生长，上线同步状态），分4阶段（种子→发芽→幼苗→成熟），每阶段有对应动森风外观变化。
- 收获：成熟后点击作物收获，自动存入仓库；批量收获（解锁权限后，一键收获所有成熟作物）；收获概率掉落稀有道具（钻石、高级肥料、装饰碎片）。

### 3. 商店/钱包/仓库系统
#### （1）商店系统
- 分类：
  - 种子区：全品类作物种子（按生长周期/季节筛选，Select组件实现）；
  - 肥料区：普通/高级/特效肥料；
  - 道具区：体力药水、批量工具、防天气道具；
  - 装饰区：农场房屋、栅栏、花草、动物摆件（动森风，纯外观，无属性加成）。
- 购买：消耗金币/钻石，点击按钮直接购买，库存不足提示（Modal弹窗）；限时折扣区（每日刷新，卡片标注折扣标签）。
#### （2）钱包系统
- 货币：
  - 金币：基础货币，通过出售作物、完成任务、签到获得；用于购买基础种子、肥料、开垦农田；
  - 钻石：付费货币，充值获得（活动少量赠送）；用于购买稀有种子、高级肥料、装饰、体力药水、解锁特权。
- 收支：记录每笔金币/钻石收支（时间、类型、金额），个人中心可查看明细。
#### （3）仓库系统
- 容量：初始50格，等级提升扩容（最高200格），可钻石购买临时扩容；
- 分类：作物（收获产物）、种子、肥料、道具、装饰；折叠面板展示，支持搜索、批量出售、批量移动。
- 出售：仓库点击作物/道具，选择出售数量，确认后获得金币；稀有道具可高价出售（限时高价收购活动）。

### 4. 任务与成就系统（引导+激励）
#### （1）任务系统
- 分类：
  - 日常任务（每日刷新）：登录、浇水3次、收获5块田、出售10个作物（奖励：金币+经验+少量钻石）；
  - 成长任务（一次性）：升级到3级、解锁10块田、收获100个作物（奖励：大量金币+经验+稀有种子/装饰）；
  - 限时任务（活动专属）：节日种植、限时收获（奖励：专属装饰、大量钻石、稀有道具）。
- 展示：底部任务入口（Tabs组件），卡片显示任务列表、进度、奖励，一键领取已完成奖励。
#### （2）成就系统
- 类型：种植成就（收获1000个小麦）、经营成就（累计出售10000金币）、成长成就（等级达到10级）、收集成就（解锁所有装饰）；
- 奖励：解锁专属头像框、农场铭牌、稀有道具、大量钻石；个人中心展示成就墙（卡片布局）。

### 5. 社交系统（轻度互动，可选）
#### （1）好友系统
- 添加：搜索昵称/ID添加好友，好友申请列表（Modal弹窗）；
- 互动：访问好友农场（查看农场布局、作物状态），帮好友浇水/施肥（每日限5次，奖励少量金币），偷取好友成熟作物（每日限3次，低概率）。
#### （2）排行榜
- 维度：农场等级、总资产、作物收获量、成就数量；每日刷新，展示前100名（卡片列表），上榜奖励少量钻石。

## 四、核心玩法流程（新手引导）
1. 注册/登录→进入新手农场（4块荒地）；
2. 新手任务引导：开垦荒地→商店购买小麦种子→播种→等待5分钟成熟；
3. 浇水（可选，加速生长）→收获小麦→出售获得金币；
4. 用金币开垦新农田、购买更多种子→循环经营；
5. 升级解锁新作物、新功能→参与任务/活动→扩建农场、解锁装饰→打造专属动物岛农场。

## 五、技术实现（基于React+animal-island-ui）
### 1. 技术栈
- 前端：React + TypeScript + Vite（匹配组件库技术栈），直接引入animal-island-ui组件（ESM格式，开箱即用）；
- 后端：Node.js + MongoDB（存储用户数据、农场数据），Redis缓存作物生长状态（离线同步）；
- 部署：Web端（适配PC/移动端，响应式布局），支持浏览器直接访问，无需下载。
### 2. 组件库使用要点
- 全局引入：`import 'animal-island-ui/style'`，直接使用Button、Input、Modal、Tabs等19个组件；
- 主题定制：覆盖40+CSS变量（如`--animal-primary-color`主色、`--animal-border-radius-base`圆角），实现农场专属动森风主题；
- 特色组件复用：Typewriter（新手引导打字动画）、Cursor（自定义农场光标）、Collapse（仓库折叠面板）、Phone（适配移动端模拟器）。

## 六、盈利模式（温和无强制）
1. 钻石充值：基础充值档位（6元=60钻石、30元=300钻石、98元=980钻石），首充双倍（送稀有种子+专属装饰）；
2. 装饰售卖：动森风农场装饰（房屋、摆件、栅栏），纯外观，无属性加成，钻石购买；
3. 限时特权：月卡（30元，每日领钻石+体力+特权：批量浇水、免广告）；
4. 活动礼包：节日/限时活动礼包（低价购稀有种子+高级肥料+装饰碎片）。

## 七、风险与优化
### 1. 风险
- 玩法单一：长期游玩易枯燥→优化：定期更新作物、装饰、活动，新增轻度玩法（养殖小动物、加工作物）；
- 数据同步异常：离线生长状态不同步→优化：后端实时计时，上线自动校准，本地缓存兜底；
- 适配问题：移动端操作不便→优化：响应式布局，简化移动端操作（一键收获、快捷商店）。
### 2. 优化方向
- 轻量化：控制包体大小，组件库按需引入，减少冗余代码；
- 低门槛：新手引导简化，操作步骤清晰，无复杂教程；
- 治愈感：强化动森风UI细节（有机形状、柔和动效、萌系插画），搭配舒缓田园背景音乐。
