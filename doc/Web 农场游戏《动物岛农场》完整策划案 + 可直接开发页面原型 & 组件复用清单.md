# Web农场游戏《动物岛农场》完整策划案 + 可直接开发页面原型&组件复用清单

---

## 一、项目基础信息
### 1. 游戏名称
动物岛农场 Web休闲农场经营游戏

### 2. 美术&UI风格
1. 全盘沿用 **animal-island-ui** 设计语言：大圆角、不规则柔和边角、3D按压按钮、马卡龙清新配色、简约卡通风
2. 场景：2.5D俯视角田园农场，草地、农田、木屋、小路、栅栏卡通手绘风
3. 交互：所有弹窗、按钮、卡片、输入框**全部复用该UI原生组件**，不自定义新样式，保证风格统一

### 3. 核心功能清单
✅ 用户注册/登录/退出/游客模式
✅ 农场主场景：农田开垦、播种、浇水、施肥、成熟收获
✅ 种子系统、肥料系统、多等级作物、离线计时生长
✅ 商店系统：种子/肥料/道具/装饰购买
✅ 仓库系统：存放作物、种子、肥料、道具，可批量出售
✅ 钱包系统：金币+钻石双货币、收支记录
✅ 角色等级、经验、升级解锁农田/种子
✅ 每日签到、日常任务、新手引导

### 页面3：农场主场景（核心页面）
**页面布局 三分结构**
1. 顶部状态栏
- 头像、昵称、等级、经验条
- 金币图标+数量、钻石图标+数量、体力值
- 设置按钮、音效开关按钮

2. 中间主区域
- 网格农田地块（初始4块，随等级解锁扩容）
- 每块农田状态：荒地→可开垦→已播种→生长中→成熟可收获
- 农田悬浮提示：作物名称、剩余成熟时间、是否需要浇水施肥

3. 底部功能导航栏
- 图标Tab：农场、背包、商店、任务、个人中心

**复用UI组件**
- Tabs 底部导航栏
- Progress 经验进度条
- Card 顶部信息卡片
- Button 农田操作按钮（开垦/播种/浇水/施肥/收获）
- Popover 农田悬浮信息提示

## 四、核心系统详细规则（可直接写接口文档）
### 1. 用户系统
- 注册：账号+密码+手机号
- 登录：账号密码登录 / 记住登录状态
- 游客模式：临时数据，提示绑定账号可永久保存
- 等级经验：收获作物、完成任务获得经验，升级解锁农田、种子、功能

### 2. 种植系统
1. 作物分三档：
   - 短期：5/10/15分钟（小麦、萝卜）
   - 中期：30/60分钟（玉米、番茄）
   - 长期：2h/4h/8h（西瓜、草莓）
2. 生长阶段：种子→发芽→幼苗→成熟 四阶段
3. 肥料效果：
   - 普通肥料：缩短30%生长时间
   - 高级肥料：缩短50% + 产量+20%

### 3. 货币系统
- 金币：种菜售卖、任务、签到获取；用于开垦、买普通种子、普通肥料
- 钻石：充值、任务、活动获取；用于稀有种子、高级肥料、仓库扩容、装饰

### 4. 背包仓库
- 所有道具统一入库，分类管理
- 支持单卖、批量卖、自动整理
- 仓库容量随等级递增

## 五、开发落地建议
1. 直接全量引入 `animal-island-ui`，**不自己写任何圆角、按钮、弹窗样式**，完全统一风格
2. 前端先做页面静态结构 + UI组件联调，再对接后端登录、存档、计时接口
3. 农田网格用二维数组存储状态，后端存数据库，前端做倒计时渲染
4. 离线生长用**时间戳差值计算**，上线自动校准作物成熟时间
